# Data Dictionary – Videodata Dataset

| Column Name      | Description                     | Data Type     | Business Relevance              |
|------------------|----------------------------------|---------------|--------------------------------|
| age              | Age of the individual            | Integer       | Helps understand age    distribution |
| workclass        | Type of employment               | Categorical   | Employment sector analysis     |
| education        | Highest education level          | Categorical   | Income analysis                |
| education-num    | Education level in numeric form  | Integer       | Numerical comparison           |
| marital-status   | Marital status                   | Categorical   | Social demographics            |
| occupation       | Job type                         | Categorical   | Profession analysis            |
| relationship     | Relationship in household        | Categorical   | Household structure            |
| race             | Race of the individual           | Categorical   | Population study               |
| sex              | Gender                           | Categorical   | Demographic segmentation       |
| capital-gain     | Capital gain amount              | Integer       | Investment income              |
| capital-loss     | Capital loss amount              | Integer       | Financial loss                 |
| hours-per-week   | Weekly working hours             | Integer       | Work intensity                 |
| native-country   | Country of origin                | Categorical   | Geographic analysis            |
| income           | Income category                  | Categorical   | Target variable                |
